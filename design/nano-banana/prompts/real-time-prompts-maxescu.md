# Nano Banana 2: Real-Time Prompt Templates
- **Source:** https://x.com/maxescu/status/2028506627767259205
- **Author:** Alex Patrascu (@maxescu)
- **Key feature:** Nano Banana 2 "Web Search" — fetches real-time data BEFORE generating

## Structure Pattern
Every prompt follows this format:
```
Category: [topic]
Data_instruction: "Search the live web for [specific real-time data]"
Characters: [who appears in the image]
Instructions: [detailed visual description with typography integration]
```

## Typography Integration Techniques
The magic is HOW text appears in the image — not as overlaid text, but as part of the scene:

1. **Environmental text** — ski tracks in snow spell words, cobblestone mosaics rearranged
2. **Material text** — athletic tape spelling stats, measuring tape forming names
3. **Negative space** — ravens flying with gaps forming sneaker silhouette
4. **Clipping mask** — giant score numbers with action photo inside letters
5. **Light refraction** — diamond refracting light that spells the price
6. **Kinetic trails** — basketball light streak forming stats
7. **Tifo mosaic** — stadium fans holding cards forming portrait + text
8. **LED projection** — arena floor as giant screen
9. **Ripped/torn reveal** — redaction tape torn to show headline
10. **Package arrangement** — shopping bags stacking to form text

## Categories with Examples

### Sports (Real-Time Data)
- **Brasileirão** — Copacabana mosaic with player name + stats
- **Liga Portugal** — Azulejo tiles with player portrait + goals
- **La Liga** — Stadium tifo mosaic portrait + score
- **Premier League** — Typographic mask (score as clipping mask) OR athletic tape spelling stats
- **F1** — POV steering wheel with race data on display, OR mixed-media scrapbook, OR kinetic typography overlap, OR track aerial
- **NBA** — LED court projection with holographic stats OR kinetic light trail from basketball
- **Tennis** — Double exposure silhouette with court inside

### Fashion & Luxury
- **Fashion Week** — Flowing silk fabric spelling designer name
- **Streetwear/Sneakers** — Raven flock negative space forming sneaker silhouette
- **Creative Directors** — Measuring tape whipping into typography
- **Sotheby's Auctions** — Diamond light refraction spelling sale price

### Tech & Commerce
- **Tech Gadgets** — X-ray schematic view with neon internals
- **E-commerce** — Cascading shopping bags forming text wall

### News & Weather
- **Breaking News** — Caution yellow + ripped black tape revealing headline
- **Ski Resorts** — Ski tracks in powder spelling snowfall amount

## Key Rules
- Always specify aspect ratio (16:9 cinematic or 9:16 story)
- Typography must be DIEGETIC (part of the scene, not overlaid)
- Use "Data_instruction" for real-time web search
- Color grading should match the cultural context
- Characters should be described with emotion/action, not static poses
