# Impeccable v1.1 — Design Fluency for AI Harnesses

**Source:** [@pbakaus](https://x.com/pbakaus/status/2029334353894162720) — Mar 4, 2026 · 1.5K likes

## What Is It

A design skill set that gives any AI harness structured "design language" for producing polished UI.

## v1.1 Changes

- All commands converted to **agent skills**
- Supports: Claude Code, VS Code, Antigravity
- Rename: `simplify` → `distill` (avoids conflict with Claude Code built-ins)
- Universal install

## Commands

`distill`, `animate`, `colorize`, `bolder`, `quieter`, `arrange`, `typeset`, `polish`, `critique`, `adapt`, `audit`

## Install

See: https://github.com/pbakaus/impeccable

## Takeaway

Install Impeccable on any agent to dramatically improve UI output quality.
