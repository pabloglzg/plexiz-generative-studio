## What This Is
An upgrade to Anthropic's original frontend-design skill. Adds 17 design commands
and 7 reference docs covering typography, color, spatial design, motion, interaction,
responsive design, and UX writing.

## Key Anti-Patterns It Fights
- Inter/Roboto/Arial as default fonts
- Purple-to-blue gradients (the "AI palette")
- Cards inside cards
- Gray text on colored backgrounds
- Pure black (#000) or white (#fff)
- Glassmorphism everywhere
- Bounce/elastic easing

## Structure
- `frontend-design/SKILL.md` — main skill (replaces Anthropic's original)
- `frontend-design/reference/` — 7 deep reference docs
- `adapt/` through `teach-impeccable/` — 17 command skills

## Usage
These skills are installed in OpenClaw at:
`~/.openclaw/workspace/skills/frontend-design-impeccable/`
