# shadcn/ui Fixes GPT-5.4 Frontend Design

## The Take

GPT-5.4 and mini are bad at frontend design on their own. No amount of prompting fixes it — the model simply isn't good enough for UI.

## The Fix (4 steps)

1. Go to `ui.shadcn.com`
2. Use their UI builder to pick components
3. Click "Copy Command"
4. Run it in your project

Now the model uses expert-crafted components instead of inventing generic UI.

## Why This Validates Our Stack

- **We already do this** — shadcn/ui is our default + Taste Rules on top
- **Confirms GPT-5.4 is weak at frontend** — validates why we use Opus as main agent for UI work and don't delegate to GPT subagents for design
- **shadcn alone isn't enough** — our Taste Rules (anti-purple, anti-center, anti-emoji, anti-card-overuse) catch what shadcn doesn't

## Engagement Context

1.8K bookmarks = extremely high save ratio. People are desperate for UI quality fixes with GPT models. This is a real pain point in the market.
