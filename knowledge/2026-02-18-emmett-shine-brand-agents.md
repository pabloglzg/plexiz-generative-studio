## Tesis
Las marcas necesitan entregar dos capas: el sistema visual/creativo para humanos (Figma, PDFs, guidelines) Y datos estructurados para agentes (YAML, Markdown, JSON). Lo llaman "dual-native brand systems."

## Puntos clave
- Figma + Claude Code integration permite loop continuo: código → Figma → diseñador refina → vuelve a código
- Solo funciona si la marca tiene datos estructurados, no solo archivos de Figma
- **Agent-First Brand Kit:** chunks de ~400 tokens con metadata parseables por agentes
- Incluye: positioning YAML, voice MD, messaging framework, personas, visual tokens JSON, terminology, guardrails
- Retrieval rules: mapean qué chunks cargar según la tarea (website copy, blog, social)
- Little Plains corre 12 agentes internos, cada uno con identity, soul, y principles files
- Ejemplo: "Donna" — agente financiero con personalidad definida en IDENTITY.md, SOUL.md, PRINCIPLES.md
- Quote de Peter Steinberger (OpenClaw): "AI doesn't replace craft. It makes craft more valuable."
- Concepto de "leapfrogging" — saltar métodos legacy e ir directo a AI-first
