# Style DNA — Forensic Voice Cloning with AI

**Source:** [@heyrobinai (Robin Delta)](https://x.com/heyrobinai/status/2029171055407849823) | 520 ❤️ | Mar 2026

## Core Insight

Describing a style doesn't work. Measuring it does.

"Casual but smart" tells Claude nothing.  
"Average sentence length 11 words, comma density 3.8 per 100, short sentence ratio 45%, zero hedging language" tells Claude everything.

## The Forensic Analyst Prompt

```
Analyze the writing sample below as a forensic style analyst. Measure and report: average sentence length, short sentence ratio (under 8 words), comma density per 100 words, vocabulary complexity, tone markers, hedging language frequency, and any verbal tics or signature phrases. Label this the Style DNA. Then write 300 words on [new topic] matching those exact metrics. Finish with a side-by-side comparison showing accuracy percentage for each metric.
```

## 3-Step Process

1. **Paste 500+ words** of target style (more = sharper clone)
2. **Get the Style DNA** — don't skip this step, it reveals what actually makes the voice distinctive vs. what you think makes it distinctive
3. **Test on new topic** — something the original writer never wrote about = real test

## What Style DNA Looks Like

```
Average sentence length: 12 words
Short sentence ratio: 40%
Comma density: 4.2 per 100 words
Vocabulary: simple, concrete, no technical jargon
Tone: direct, slightly informal, zero hedging
Verbal tics: repeating subject at start of consecutive sentences for rhythm
```

## Use Cases

- Ghostwriting that sounds like the client, not like you trying
- Guest posts that match publication voice exactly
- Emails that still sound like you when running on empty
- Learning tool: clone 5 writers = more style understanding than years of reading

## The Accuracy Comparison

The side-by-side accuracy % is the killer feature — you can see exactly where the clone drifts and calibrate.
