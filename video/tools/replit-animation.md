# Replit Animation — Video as Code

**Source:** [@mattyp (Matt Palmer, Replit)](https://x.com/mattyp/status/2024616947934253269) | 202 ❤️  
**Date:** Feb 2026

## What It Is

Create animated videos directly in Replit from a prompt. Builds via TypeScript + modern animation libraries. Export to MP4 or hosted URL.

## Video as Code Advantage

Code = source of truth. Pull in:
- Existing design systems and tokens
- Typography styling
- Brand guidelines
- Agent skills

Replit used their own production UI components in the opening animation — exact styling from production systems.

## Use Cases
- Product marketing pipeline → weekly changelog videos
- Feature releases pulling latest brand styling
- Any repeatable video content at scale

## Getting Started

In Replit prompt box: mention "video" → toggles video mode  
OR select "Animation" from dropdown under App mode

## Tips for Better Output

- Learn video terminology: J-cuts, L-cuts, jump cuts
- Ask agent to research terminology and teach you the lingo
- Combine with Agent Skills like `video-motion-graphics` for refined camera control
- Once getting good outputs → create repeatable workflows and systems

## Key Concept

Video creation is now a pipeline — just like data or CI/CD.
