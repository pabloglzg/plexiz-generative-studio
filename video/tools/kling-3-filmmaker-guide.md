## The Core Shift

Kling 2.x thought in shots. Kling 3.0 thinks in **coverage** (sequences).

One prompt → multiple connected shots with transitions and continuity. The 3-15 second "limit" is a feature — it matches how scenes are built on set.

## Key Features

### 1. Multi-Shot Generation as Moving Storyboards
Define 3-15s sequences that feel like rough animatics. Each run = one beat (entry / conflict / reaction).

### 2. Subject/Character Consistency (Subject Binding)
Same jacket, same face, same hair across angles and shots.  
**Critical:** Repeat exact character descriptors every shot. Don't say "the guy" — say "tall man with red neon jacket and scar over left eyebrow" every time.

### 3. Camera Language as First-Class Prompts
- Slow dolly in
- Crane down reveal
- Chaotic handheld chase
- POV through rain-streaked visor
- Whip pan from detective to suspect

Camera choice changes emotion more than megapixels.

## 5-Part Prompt Format (Cut Retries in Half)

1. **Who** — Character with full descriptor
2. **What** — ONE clear action per shot
3. **Where** — Environment/setting
4. **Appearance/Style** — Visual aesthetic
5. **Camera** — Specific camera move

## Example 4-Shot Sequence

```
Shot 1: Wide crane down into alley. Neon signs flicker. Thief leans on wet brick wall, checking holographic watch. Slow dolly in. Distant traffic hum and light rain.

Shot 2: Medium over-shoulder as thief studies locked door. 35mm lens feel. Subtle handheld sway. Street noise dips. Focus on lock's beeps.

Shot 3: Insert on gloved hands picking lock. Shallow DoF. Quick crash zoom as it clicks open. Tiny UI beeps and close rustle.

Shot 4: POV as door swings inward. Interior darkness blooms. Synth hit swells. Camera creeps forward, hesitant.
```

## Credit Management (from $1,000 experiment)

- ~$0.50-$1.50 per **usable** clip after retries
- 45% of budget: experiments that never left drafts
- 35%: retries of "almost there" shots  
- 20%: actual keepers

**Rules to avoid credit burn:**
- Avoid 3s clips — minimum 12-15s for editing room
- Plan shot list before generating
- Treat like a shoot day, not a casino

**Session budgets:**
- Hobbyist: 5-10 gens/session
- Serious creator: 20-30/project
- Agency work: 40-80 with strict shot list

## Image-to-Video

Start with key art still or character design → Kling 3.0 moves that person through a sequence. Best way to lock character across shots.
