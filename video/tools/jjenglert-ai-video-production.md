**Source:** [@JJEnglert](https://x.com/JJEnglert/status/2030738657339130128) | 1,193 ❤️ | Mar 2026  
**Context:** Trained filmmaker/producer, now creating for major brands with this setup

## The Stack

| Tool | Role |
|------|------|
| Claude Code | Script → motion graphic code (2 min turnaround) |
| Descript | Center editing timeline |
| Remotion | Preview/edit motion graphics |
| ElevenLabs | Voice + sound design |
| Python music lib | Background tracks from text prompt |

## Workflow

1. Build all scenes/templates from a central brand style guide (15+ templates)
2. For new motion graphic: copy script section from Descript → paste to Claude Code
3. Get back production-ready code in ~2 minutes
4. Drop into Descript timeline

## Key Insight

Video production is now a pipeline — like data or CI/CD. Learn the tools, build templates, systemize everything.

> "I spent years learning After Effects, Premiere, Final Cut. And now the most efficient production workflow I've ever used is a code editor, a couple APIs, Descript and a programmatic video tool."
