## Key New Insights (beyond articles)
- **Prompt structure color-coded:** Camera → Subject → Action → Environment → Lighting → Texture → Audio
- **Multi-shot = up to 6 shots per generation**, each with custom duration (within 15s total)
- **Multi-shot NOT available with both start AND end frame** — only with start frame or text-only
- **3 methods:** Text-to-video (least control), Multi-shot (medium), Image-to-video with start/end frame (most control)
- **Image-to-video is the most popular and most control** — start frame = reference, AI only does motion
- **Continuous video technique:** Grab last frame of clip → use as start frame of next generation
- **References (Omni model):** Up to 7 visual references per generation — characters, locations, props
- **3-angle character trick:** Feed AI front/side/back angles of character to prevent glitching
- **Use Nano Banana Pro** to generate 3 angles from one character image (prompt in video)
- **Meta-prompting:** Feed Kling docs + character image to ChatGPT → get optimized multi-shot prompt
- **Lip sync breaks after 10 seconds** — keep dialogue in first 10s, action-only for remaining 5s
- **Morphing increases with complexity and length** — simpler prompts or <10s = less morphing
- **Kling 3.0 is MUCH better than 2.6 and Veo 3.1** at prompt coherence
- **Expressions and emotions are Kling 3.0's strength** — extremely realistic
- **Consistency across shots is good** — remembers details (wall marks, lighting, clothing) between multi-shots
- **Movement carries between shots** — if character is leaning in at end of shot 1, shot 2 picks up that lean
